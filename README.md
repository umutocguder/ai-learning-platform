## 🌟 Key Features & Interactive Laboratories

- **Interactive Tokenizer & Context Visualizer**: Real-time breakdown of input text into BPE token chunks, visual attention heatmaps, and context length indicators.
- **Sampling Laboratory**: Live playground to test the effects of `temperature`, `top_p`, `top_k`, and `repetition_penalty` on text generation diversity and determinism.
- **Prompt Engineering Sandbox**: Structured templates for Few-Shot prompting, Chain-of-Thought (CoT), System-User separation, and JSON schema constraints.
- **Model Context Protocol (MCP) Simulator**: Visual flow demonstration of how LLMs connect to external tools, databases, and local filesystem resources via standardized MCP client-server schemas.
- **Knowledge Assessment & Quizzes**: In-browser quizzes with immediate explanations and progress badges for each completed track.

---

## 📚 Curriculum Tracks

1. **Foundations of Modern AI**: Attention mechanisms, transformer architectures, tokenization, context windows, and scaling laws.
2. **Advanced Prompt Engineering**: Prompt decomposition, role prompting, self-consistency, ReAct framing, and hallucination reduction.
3. **Retrieval-Augmented Generation (RAG)**: Chunking strategies, vector embeddings, similarity search, reranking, and semantic caching.
4. **Autonomous AI Agents**: Tool calling, decision loops, execution sandboxes, multi-agent coordination, and memory persistence.
5. **Diffusion & Multimodal AI**: Latent diffusion models, image conditioning, LoRA fine-tuning, and audio-video generation paradigms.

## 🚀 Running Locally

### Prerequisites

- [Node.js 18+](https://nodejs.org/)

### Quickstart

```bash
# Clone the repository
git clone https://github.com/umutocguder/ai-learning-platform.git
cd ai-learning-platform

# Install dependencies
npm install

# Run automated test suite
npm test

# Launch local development server
npm start
```

Navigate to [http://localhost:3000](http://localhost:3000) to start learning.
